# Choco Port — upgraded portfolio

Upload the contents of this folder to GitHub and connect the repository to Netlify.

## Structure
- index.html
- css/style.css
- js/main.js
- js/translations.js
- assets/favicon.svg
- robots.txt
- sitemap.xml
- netlify.toml

The site includes responsive design, dark/light mode, AZ/EN language switching, portfolio filtering, animations and a contact form UI.
